# Cast-R1 project page

Static project website for [Cast-R1](https://github.com/ustc-time-series/Cast-R1).

Published with GitHub Pages from this branch, at:
https://ustc-time-series.github.io/Cast-R1/

Edit `index.html`, `styles.css`, and `app.js` to update the page.
Benchmark values are from the revised manuscript. Case replay coordinates are
extracted from the manuscript vector figure and are approximate plotted values,
not raw benchmark observations or live model inference.
